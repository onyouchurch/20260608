# 📚 독서수첩 (Reading Journal)
> **Youn Sang Young 목사의 영적 성장과 목회 활동을 돕는 개인 맞춤형 설치형 독서 기록장**

삼성 **Galaxy One UI 7**의 디자인 철학을 반영하여, 스마트폰 한 손 조작에 최적화된 반응형 UI와 오프라인 동작을 보장하는 **설치형 웹앱 (PWA)** 형태로 제작되었습니다. 모든 데이터는 인터넷 연결 없이 브라우저 내 IndexedDB(Dexie.js)에 완벽히 로컬 저장됩니다.

---

## 🌟 주요 기능

1. **대시보드 (홈)**
   - 등록 도서 수, 읽는 중인 책, 완독한 책, 이번 달 완독 권수 등 직관적인 요약 통계 제공.
   - 현재 읽고 있는 책 목록에서 바로 독서노트를 기록할 수 있는 한 손 조작 퀵 링크 지원.
   - 독서노트 작성 및 인용문 등록에 대한 최신 활동 피드 제공.

2. **내 책장 (도서 관리)**
   - 상태별 필터 (읽고 싶은 책 / 읽는 중 / 읽은 책 / 중단한 책) 및 카테고리별 필터.
   - 책 제목, 저자, 출판사, 키워드를 통합 검색하는 서치바 제공.
   - 최근 등록순, 시작일순, 마침일순, 별점순, 제목순 정렬 기능.
   - 표지 이미지가 없는 책은 제목과 카테고리에 맞춰 **파스텔 그라데이션의 세련된 표지**를 자동 생성하여 표시.

3. **독서 기간 설정 및 자동 계산**
   - 도서 상태 변경 시 시작일/마침일을 캘린더 Date Picker로 손쉽게 입력.
   - 시작일과 마침일을 기준으로 "총 X일 동안 읽음" 문구 자동 계산 및 유효성 검사 (마침일이 시작일보다 빠를 경우 저장 불가).

4. **독서 캘린더 (달력)**
   - 월간 달력 형태로 독서 흐름을 한눈에 파악.
   - 독서 시작일, 마침일, 독서노트 작성일, 인용구 등록일을 날짜별 색상 점(Dot) 배지로 표시.
   - 특정 날짜 선택 시 화면 하단에서 One UI 스타일의 **바텀 시트(Bottom Sheet)**가 부드럽게 활성화되어 일별 상세 활동 조회 가능.
   - 달력 화면에서 직접 도서를 선택하여 오늘 분량 독서노트를 즉시 추가하는 단축 기능 지원.

5. **집중형 독서 노트 및 인용문 수첩**
   - 책별 독서 노트를 일자/페이지 단위로 무제한 작성 가능.
   - **요약, 핵심 구절, 느낀 점(묵상), 적용할 점(실천 계획), 태그** 항목을 구분하여 깊이 있는 묵상을 돕는 집중 레이아웃.
   - 책 속의 보물 같은 문장들을 별도 수집하는 **인용구 수첩** 지원 (페이지 번호, 한 줄 메모, 주제 태그 포함).

6. **통계 대시보드**
   - 가독성이 뛰어난 Custom SVG 월별 독서량 막대 그래프.
   - 카테고리별 분포율(%)을 시각화한 수평 진행 표시줄.
   - 가장 빠르게 읽은 책, 가장 오랫동안 정독한 책 등 흥미로운 독서 패턴 지표 산출.

7. **설정 및 데이터 백업/복원**
   - **라이트 모드 / 다크 모드 / 시스템 테마** 선택 지원.
   - **한 손 조작 모드** 온/오프 (모바일 환경에서 주요 컨트롤과 상단 타이틀을 화면 아래쪽으로 내려 터치 범위를 최적화).
   - 신학, 목회, 성경 연구, 신앙 일반 등 기본 제공 카테고리 외에 사용자가 직접 카테고리를 추가/삭제할 수 있는 관리 기능.
   - 모든 데이터를 안전하게 파일로 소장할 수 있는 **JSON 백업/복원** (스마트폰과 PC 간 수동 데이터 연동 용이).

## 🛠️ 기술 스택 (Tech Stack)

- **프레임워크**: React 19 + TypeScript + Vite 6
- **스타일링**: Tailwind CSS v4 (삼성 One UI 7 디자인 철학 가이드 적용)
- **아이콘**: Lucide React
- **로컬 저장소**: IndexedDB (구현 최적화를 위해 Dexie.js 4 사용)
- **PWA 기술**: Service Worker (오프라인 정적 파일 캐싱), Web App Manifest

## 🚀 로컬 실행 방법 (PC 실행 및 개발 서버 구동)

현재 프로젝트 폴더(`.node/`)에 개발용 포터블 Node.js가 포함되어 있으므로 별도의 Node.js 설치 과정이 필요하지 않습니다.

1. **터미널 실행 및 폴더 이동**
   터미널(PowerShell 등)을 열고 프로젝트 폴더로 이동합니다:
   ```bash
   cd "C:\Users\u14ra\.gemini\antigravity\scratch\독서수첩"
   ```

2. **환경변수 설정 및 패키지 설치**
   아래 명령어를 실행하여 로컬 포터블 Node.js 경로를 추가하고 의존성 패키지를 설치합니다:
   ```powershell
   $Env:Path = "C:\Users\u14ra\.gemini\antigravity\scratch\독서수첩\.node\node-v22.11.0-win-x64;" + $Env:Path
   npm install
   ```

3. **로컬 개발 서버 실행**
   개발 서버를 구동합니다:
   ```powershell
   npm run dev
   ```
   실행 후 브라우저에서 `http://localhost:5173` 주소로 접속하면 앱을 사용하실 수 있습니다.

4. **Vite 프로덕션 빌드 (배포용 파일 생성)**
   ```powershell
   npm run build
   ```
   빌드가 완료되면 `/dist` 폴더에 정적 파일들이 생성됩니다. 이 파일들을 웹 서버(GitHub Pages, Vercel, Firebase Hosting 등)에 올리면 즉시 실제 서비스 운영이 가능합니다.

## 📱 스마트폰 및 PC 앱 설치 방법 (PWA)

### 1. Android (Galaxy Chrome, Samsung Internet 등)
1. 크롬 또는 삼성인터넷 브라우저로 `http://localhost:5173` (또는 실제 배포 주소)에 접속합니다.
2. 앱 내 **설정(Settings) -> 독서수첩 앱 설치 정보**로 이동합니다.
3. **"스마트폰/기기에 앱 설치하기"** 버튼을 터치하거나 브라우저 주소창 메뉴에서 **'앱 설치'** 또는 **'홈 화면에 추가'**를 선택합니다.
4. 홈 화면에 독서수첩 아이콘이 생성되어 일반 앱처럼 독립된 창(Standalone)으로 사용 가능합니다.

### 2. iOS (iPhone/iPad Safari)
1. 사파리(Safari) 브라우저로 접속합니다.
2. 화면 하단 중앙의 **공유 버튼** (네모 속 위를 향한 화살표)을 터치합니다.
3. 메뉴 리스트에서 **'홈 화면에 추가'**를 터치합니다.
4. 바탕화면에 설치되어 오프라인 환경에서도 완전하게 독립 실행됩니다.

### 3. PC (Chrome, Edge 브라우저)
1. PC 브라우저로 사이트에 접속합니다.
2. 브라우저 우측 상단 주소창 영역에 표시되는 **'앱 설치' 아이콘**(모니터 모양 또는 플러스 버튼)을 클릭합니다.
3. 바탕화면에 바로가기 앱이 생성되며, 데스크톱 단독 창 모드로 작동합니다.

## 📂 프로젝트 구조 (Codebase Structure)

- `src/db/db.ts`: IndexedDB 선언 및 데이터베이스 초기 샘플 데이터 시딩
- `src/types/index.ts`: 도서(Book), 노트, 인용구, 이벤트, 설정 인터페이스 정의
- `src/hooks/`: 설정을 동기화하고 로컬 DB의 데이터 처리를 reactive하게 돕는 React Custom Hooks
  - `useBooks.ts`: 도서 CRUD 및 실시간 통계 계산
  - `useSettings.ts`: 테마(다크/라이트), 한 손 모드 및 카테고리 동기화
  - `usePWAInstall.ts`: PWA 설치 프롬프트 브라우저 이벤트 제어
- `src/utils/`: 날짜 계산 및 JSON 데이터 백업/복원 유틸리티
- `src/components/`: 재사용 가능한 UI 블록
  - `Layout.tsx`: One UI 7 축소형 상단 헤더, 모바일 하단 탭바, PC 사이드바 네비게이션
  - `BookCover.tsx`: 도서 데이터 기반 dynamic HSL 그라데이션 표지 렌더러
  - `OneUICalendar.tsx`: 이벤트 닷 배지를 탑재한 반응형 커스텀 캘린더
  - `BottomSheet.tsx`: 모바일 한 손 조작용 바텀 시트 슬라이더
- `src/pages/`: 각 메뉴별 상세 화면 컴포넌트 모음
- `public/`: manifest.json 파일 및 AI가 생성한 고화질 로고 이미지 에셋 보관
